# Go/NoGo auf einer Paraphrase

**Datum:** 2025-03-25 · **Mechanik danach:** Hard-Gate Quelle in `AGENTS.md`, Kopfzeilen **Quelle/Abruf/Publiziert** in jeder Anzeige

## Was passiert ist

Eine Empfehlung stuetzte sich auf eine Zusammenfassung der Anzeige statt auf den Volltext. Die Zusammenfassung liess das harte Kriterium «100 % vor Ort» weg.

## Regel

Keine Bewertung ohne vollstaendigen Volltext aus der Primaerquelle. Eine Paraphrase zaehlt nie als Quelle, auch keine eigene. Jede Empfehlung nennt die verbatim abgelegte Datei, auf der sie beruht.
